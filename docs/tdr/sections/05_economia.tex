\section{Cumplimiento legal y paso a producción}
Antes de una utilización real se debe:
\begin{enumerate}[label=\arabic*.]
\item actualizar las geometrías oficiales de SERNANP;
\item incorporar cierres temporales vigentes;
\item transformar todas las capas al mismo CRS;
\item eliminar nodos y aristas prohibidas;
\item verificar cero violaciones legales;
\item detener el despacho si las capas regulatorias no pueden validarse.
\end{enumerate}
