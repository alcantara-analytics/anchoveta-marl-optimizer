\section{Conclusiones}
El TDR se resuelve mediante una arquitectura híbrida de asignación y ruteo. Para la fotografía estática disponible, MILP constituye el benchmark más eficiente. MARL debe considerarse una extensión orientada a decisiones secuenciales y dinámicas.
La principal condición pendiente para uso operacional es la materialización de la máscara legal y los cierres temporales vigentes. El sistema debe operar bajo una regla conservadora: si las restricciones legales no están verificadas, no debe generar una orden de despacho.
